# Fupa Cryptocurrency White Paper

Official white paper for **Fupa**, a transparent cryptocurrency on PulseChain.

## Overview

Fupa is a commodity-style cryptocurrency designed with a split-pool liquidity architecture. This structure enables arbitrage activity that can contribute to trading volume across the ecosystem.

The project prioritises **full transparency** through burned liquidity positions and renounced contracts.

## Key Characteristics

- Split-pool liquidity design for arbitrage opportunities
- Burned liquidity positions
- Renounced contracts (where applicable)
- Fixed supply
- Zero transaction taxes
- No staking mechanism (and none planned)
